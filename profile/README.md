# Post-classical

**音楽と絵画が出会う、オーディオビジュアル・パフォーマンス。**

ヴァイオリンの生演奏に電子音楽と映像を重ね、クラシック音楽と絵画をつなぐ表現に取り組んでいます。

## Post-Classical Debussy

ドビュッシーの4作品を、モネやゴッホの絵画と組み合わせて上演する公演です。
音の強弱や持続に応じて変わる光と粒子の映像が、演奏と絵画の世界を結びます。

### 音楽と絵画

| ドビュッシーの作品 | 組み合わせる絵画 |
| --- | --- |
| 月の光 | モネ《月明かりの船出》 |
| アラベスク 第1番 | ゴッホ《星月夜》 |
| ヒースの茂る荒れ地 | ゴッホ《手押し車のある風景》 |
| 亜麻色の髪の乙女 | モネ《ヒナゲシの野》 |

### 出演

- **Marcy MIWA** — クリエイティブテクノロジスト。演奏に応答する映像を担当。
- **SYIA** — ヴァイオリニスト。ヴァイオリンの生演奏を担当。
- **金子淳平** — サウンドアーティスト。絵画を音へと展開する制作に取り組む。
